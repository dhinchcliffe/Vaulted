Save to Vaulted

Share a Safari page or an X post, then review Autofile’s suggested folder in Vaulted. Your note is saved in ReadItLater Inbox before AI runs.

  1. Copy this token now. It is shown only once. Keep it private: it allows new captures, but cannot read or change existing notes.

  2. Download Save to Vaulted

    Open the downloaded file in Shortcuts (or Files → Downloads → Save-to-Vaulted.shortcut). Tap Set Up Shortcut, paste your token when asked, then Add Shortcut.

  3. In Safari, open a page, tap Share, then Save to Vaulted. Allow the requested webpage access and connection to vaulted-sable.vercel.app. Sign into Vaulted if asked. Edit the suggested folder and tap File Here.

If Safari capture asks you to enable scripts: Settings → Apps → Shortcuts → Advanced → Allow Running Scripts. To find the shortcut in Share, scroll down; use Edit Actions to add it to Favorites.

From X

Tap the post’s Share icon → Share via… → Save to Vaulted. Vaulted attempts to retrieve the public post’s full text and still images. Foreign-language posts get a clearly labeled English translation first, with the original captured content preserved below. English posts are kept as they are. If translation is unavailable, the original still saves with a notice. Translation may differ from the wording shown in X. It always preserves the source URL. Public X lookup and translation use FxTwitter, which receives only the post ID, never your token or vault contents. If needed, Vaulted’s existing AI service translates the captured post text.

If X retrieval is unavailable, the source link and any shared text are saved with an explanation. For a fuller capture, open the post in Safari, expand any “Show more” text, then share it from there. Protected posts require sharing the content you can view in Safari or copied text. No video is imported.

Images are copied into Vaulted’s Attachments/Web folder, with references that survive moving the note. If an image cannot be copied, the note marks it and retains an original-source link. Full X Articles and entire threads are not guaranteed. This shortcut is intended for one page or post at a time.

Reddit phone-fetch experiment

This separate test starts from the Reddit app and asks your iPhone to retrieve the public post data. Your existing Save to Vaulted shortcut stays unchanged. Reddit may still refuse the request; this is an experiment, not a verified workaround.

Create and copy a shortcut token above, then download Reddit to Vaulted Test. Open the file in Shortcuts, paste the token during setup, and add it. In Reddit, tap Share → More → Reddit to Vaulted Test. Allow connections to reddit.com and vaulted-sable.vercel.app if prompted. The token is sent only to Vaulted.

If successful, Vaulted saves the post and opens Autofile. Images use the same vault storage; video is omitted. If Shortcuts shows a network error or Vaulted says Reddit did not return a readable post, report that exact message. Do not replace your working Shortcut. This test does not open Safari automatically.
